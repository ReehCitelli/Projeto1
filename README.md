# 🌸 Portfólio Pessoal — Renata Citelli

Portfólio pessoal desenvolvido do zero como cartão de visita digital e vitrine da minha evolução como desenvolvedora em transição para a área de Ciência de Dados.

🔗 **[Ver projeto ao vivo](https://reehcitelli.github.io/Projeto1/index.html)**

---

## ✨ Funcionalidades

- **Tema Dark / Rose** — alternância suave entre fundo escuro e rosa suave
- **Menu overlay fullscreen** — hamburger animado com links em tipografia display
- **Efeito scroll-lit** — títulos que "acendem" palavra por palavra conforme o scroll
- **Cursor customizado** — cursor com anel animado que acompanha o mouse
- **Marquee de tecnologias** — faixa contínua com as skills em loop
- **Seção Sobre** com foto e efeito hover (preto e branco → colorido + borda rosa)
- **Lista de projetos** com hover interativo estilo editorial
- **Totalmente responsivo** para mobile

---
